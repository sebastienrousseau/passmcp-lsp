## Highlights ⭐️

* **Catch mistakes in MCP files while you type**: passmcp-lsp checks `server.json` against the MCP Registry's schema, and flags broken or risky entries in Claude Desktop, Claude Code, Cursor and VS Code client configurations, including credentials written into them.
* **Policies and attestations as passmcp reads them**: a policy passmcp would refuse is an error in the editor, with passmcp's reason, and an attestation is verified offline by passmcp-reporting.
* **passmcp's guidance on hover**: hover a check id in a policy or an attestation to see what the check means and how to fix it, from the passmcp you have installed.
* **In the editor or in CI**: a VS Code extension, a Neovim configuration, and `passmcp-lsp check` for a pipeline.
