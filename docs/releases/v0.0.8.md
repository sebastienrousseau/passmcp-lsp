## Highlights ⭐️

* **In lockstep with passmcp 0.0.8**: passmcp-reporting is required at v0.0.8, whose attestation verifiers are unchanged from v0.0.7, and the policy rules and hover are cross-checked against passmcp v0.0.8. The language server's own code and its diagnostics are unchanged.
* **Issue templates, and no more pointers to Discussions**: bug report and feature request forms are added, with a chooser that sends vulnerabilities to private reporting and check verdicts to passmcp. SUPPORT.md no longer sends questions to GitHub Discussions, which are not enabled; a question is a GitHub issue.
* **Release workflow on `goreleaser/goreleaser-action` 7.3.0**, pinned by commit.
