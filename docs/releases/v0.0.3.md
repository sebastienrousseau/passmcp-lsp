## Highlights ⭐️

* **Same server, the family's new version**: the language server is unchanged from 0.0.2. passmcp-lsp moves to 0.0.3 with passmcp, whose family manifest now lists it as released.
* **An accurate README**: capabilities are marked released in 0.0.2 with a link to the release, and the README says plainly that `go install` waits on satellion.com serving the module's import path.
* **The VS Code extension builds with TypeScript 7.0**: it still targets VS Code 1.91 and later, so it installs in the same editors as before.
