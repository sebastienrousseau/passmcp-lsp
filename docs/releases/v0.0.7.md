## Highlights ⭐️

* **Joins the family at 0.0.7**: passmcp-lsp did not ship a 0.0.6, so it moves from 0.0.5 straight to the family's version. The language server's own code is unchanged.
* **VS Code extension dependencies**: `@types/node` moves to 26.6.5, and `@types/vscode` stays at 1.91, the oldest VS Code the extension supports. The 0.0.5 highlights said it had moved to 1.140.0; it had not.
* **Built with Go 1.26.9**: the release binaries no longer ship Go 1.26.8's standard library, which carries GO-2026-6599 to GO-2026-6617; none was reachable from this code.
